# 영유아·어린이 서비스 전환

## 계정과 아이

- 카카오 신규 로그인은 보호자로 자동 등록한다. 기존 역할 선택 API를 호출한다면 `{"role":"CAREGIVER"}`만 허용되며, 개인(PATIENT) 선택은 공개 요청에서 거부한다.
- 첫 부모는 `POST /api/children`에 `{"name":"아이 이름","birthDate":"2024-03-01"}`을 보내 아이를 등록한다. 응답의 `id`는 진료·문서·건강기록 API에서 사용하는 `patientId`다.
- 다른 부모는 별도 카카오 계정으로 가입하고 `POST /api/children/join`에 `{"inviteCode":"초대 코드"}`를 보낸다. 부모 두 명까지 활성 연결을 허용한다.
- `GET /api/children`으로 로그인한 부모의 아이 목록을 조회한다. 두 계정은 같은 아이 ID를 사용하므로 기록과 AI 문서 설명을 함께 볼 수 있다.
- 기존 환자 프로필은 이름을 추측하지 않고 `이름 확인 필요`로 이관한다. 부모가 `PUT /api/children/{id}`에 아이 이름과 생년월일을 보내 확인한다.
- 초대 코드는 아이 의료정보 접근 권한을 부여한다. 화면에서는 공유 대상을 분명하게 보여주고, 향후 초대 코드 재발급·만료 기능을 제공하는 것이 좋다.

## 현재 기능의 어린이 중심 명칭

| 기존 기능 | 어린이 서비스에서의 용도 |
| --- | --- |
| 방문 기록 | 아이 진료·검진 방문 및 다음 예약 |
| 의료 문서 업로드·분석 | 아이 검사 결과, 처방전, 진단서, 퇴원 안내 저장과 항목 추출 |
| AI 채팅·설명 문서 | 부모에게 아이 의료 문서의 원문 근거와 쉬운 설명 제공 |
| 건강 기록 | 아이 증상, 체온, 복약 관찰 등 부모 작성 기록 |
| 일정·할 일·알림 | 재진, 검사, 복약 확인, 예방접종 일정으로 확장 가능 |
| 타임라인 | 아이의 의료 이력을 시간순으로 표시 |

## 남은 화면 작업

현재 `MediBridge_frontend` 저장소에는 README만 있어 실제 UI를 수정할 수 없다. 로그인 후 개인/보호자 선택 화면을 부모 가입으로 바꾸고, 아이 등록·초대 코드 입력·아이 전환 화면을 위 API에 연결해야 한다. 목록·문서·AI 채팅·건강기록 요청에는 선택한 아이의 `patientId`를 보내야 한다.
