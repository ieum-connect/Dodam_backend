# 성장 기록 API

아이별 측정일·키(cm)·몸무게(kg)·메모를 저장한다. 키 또는 몸무게 중 하나 이상 필요하며, 소수점 한 자리까지 입력한다. 미래 및 아이 생일 이전 날짜는 거절한다. 입력 상한은 잘못된 단위 입력 방지용이며 의학적 정상 범위를 의미하지 않는다.

- `GET /api/growth-records?patientId={id}`: 삭제되지 않은 기록, 측정일 내림차순.
- `POST /api/growth-records`: `patientId`, `measuredOn`, `heightCm`, `weightKg`, `note`. 생성 시 201.
- `PUT /api/growth-records/{id}`: 같은 입력과 조회한 `version` 필요. 아이 변경 불가.
- `DELETE /api/growth-records/{id}?version={version}`: 소프트 삭제, 204.

같은 아이·측정일에는 하나의 유효한 기록만 허용한다. 중복 날짜와 오래된 version은 409. 본인 또는 ACTIVE 가족 관계만 조회·작성·수정·삭제할 수 있다. 관계가 해제되면 접근 불가. 가족은 작성자와 무관하게 기록을 수정할 수 있으며 기존 건강기록 접근 정책을 따른다.

DB 변경: `V202611071100__growth_records.sql`. 아이·날짜의 부분 유일 인덱스와 입력 범위 CHECK 제약을 적용한다. 생성·수정은 아이 행 잠금으로 날짜 중복 검사를 직렬화하고, 수정·삭제 충돌에는 낙관적 잠금을 적용한다.

프런트는 3개월/6개월/1년/전체 기간, 키/몸무게 전환, 날짜 간격에 비례하는 그래프를 제공한다. 기간은 오늘(한국 날짜)에서 3·6·12개월 전의 같은 날짜까지이며, 월말은 해당 월의 말일로 보정한다. 그래프 가로축은 선택한 전체 기간으로 고정하므로 기록이 없는 구간도 유지한다. 점 선택으로 날짜와 값을 확인하고 기간 내 첫·마지막 측정값 차이를 표시한다. 최신 수치 카드는 전체 기록 중 항목별 최근 두 측정값을 비교하며, 측정일을 함께 표시한다. 백분위·정상 판정·AI 분석은 제공하지 않는다.

검증: `GrowthApiIntegrationTest` — CRUD, 수정·삭제 버전 충돌, 날짜 중복, 입력 범위, 미래·생일 이전 날짜, 타인·비로그인 차단, ACTIVE 가족 접근과 관계 해제 후 차단. 로컬 PostgreSQL 마이그레이션 및 화면 입력·수정·기간 전환·단독 몸무게·삭제를 확인했다. 화면 검증 데이터는 가상 측정값이다.
