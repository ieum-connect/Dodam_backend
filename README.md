# 도담 (Dodam) Backend

도담은 아이의 건강·성장 정보와 가족의 돌봄 상황을 한곳에 모아, **현재 우리 가족에게 필요한 복지 프로그램을 맞춤 추천하는 가족 돌봄 서비스**입니다.

## 서비스 한 줄 소개

흩어진 아이 건강 기록과 복지 정보를 연결해, 보호자가 놓치기 쉬운 지원 제도를 아이의 나이·상태·지역·가족 상황에 맞춰 찾아주고 신청까지 이어지도록 돕습니다.

## 문제 상황과 페인포인트

- 복지 제도와 지원 프로그램이 여러 기관·웹사이트에 흩어져 있어 무엇을 받을 수 있는지 알기 어렵습니다.
- 지원 대상, 소득 기준, 지역 조건, 신청 기간을 일일이 비교해야 해 보호자의 탐색 부담이 큽니다.
- 예방접종·진료·성장 기록이 여러 문서와 앱에 나뉘어 있어 상담이나 신청에 필요한 정보를 다시 정리해야 합니다.
- 맞벌이·한부모·다자녀 가정은 돌봄 시간이 부족해 필요한 지원을 알고도 신청 시기를 놓치기 쉽습니다.
- 가족 보호자마다 정보가 달라 중복 신청, 누락, 잘못된 안내가 발생할 수 있습니다.

## 해결 방식

도담 백엔드는 아이 프로필, 건강·성장 기록, 보호자 관계, 지역과 생활 조건을 안전하게 연결합니다. 이 데이터를 기반으로 복지 프로그램을 검색·필터링하고, 조건에 맞는 지원을 우선순위와 함께 추천합니다. AI 상담은 복지·건강 문서를 바탕으로 근거를 확인하며 답하고, 추천 결과와 상담 기록은 가족 보호자가 함께 확인할 수 있습니다.

### 핵심 기능

1. **복지 프로그램 맞춤 추천** — 아이 정보와 가족 상황을 기준으로 받을 가능성이 높은 프로그램을 선별하고 자격 조건·신청 방법·기한을 안내합니다.
2. 아이 프로필·건강 기록 관리 — 예방접종, 진료, 성장 기록과 문서를 아이별로 관리합니다.
3. AI 도담 상담 — 등록 문서와 서비스 지식을 바탕으로 돌봄·복지 질문에 답하고, 불확실한 내용은 확인이 필요하다고 표시합니다.
4. 가족 보호자 연결 — 보호자 관계를 등록해 가족이 같은 아이의 기록과 추천 결과를 공유합니다.
5. 문서 기반 RAG — 업로드한 문서를 색인해 상담과 추천의 근거로 활용합니다.

## 기술 구성

- Java 17, Spring Boot, Spring Web / Validation / Data JPA / Security
- PostgreSQL + pgvector
- Python FastAPI AI 서버(Gemini 연동)
- Maven, Docker Compose

## 로컬 실행

```powershell
# PostgreSQL 실행
docker compose up -d postgres

# 서버 실행 (Windows)
.\mvnw.cmd spring-boot:run
```

기본 Spring API 주소는 `http://localhost:8081`이며, AI 서버를 별도로 실행하는 경우 FastAPI 주소는 `http://localhost:8000`입니다.

### 데모 데이터

`dummydata/all-dodam-demo.sql`은 아이·보호자·건강 기록·복지 추천·문서·AI 상담에 필요한 데모 데이터를 한 번에 넣는 진입점입니다. `dummydata` 폴더 전체를 컨테이너에 복사한 뒤 실행해야 상대 경로 include가 정상 동작합니다.

```powershell
docker cp .\dummydata dodam_backend-postgres-1:/tmp/dummydata
docker exec -e PGCLIENTENCODING=UTF8 dodam_backend-postgres-1 `
  psql -U dodam -d dodam -f /tmp/dummydata/all-dodam-demo.sql
```

채팅 기록만 비우려면 마지막에 `dummydata/reset-chat-history.sql`을 별도로 실행합니다. 통합 시드 파일 자체는 채팅 기록을 자동 초기화하지 않습니다.

## 품질과 안전

- 요청 값 검증과 일관된 오류 응답으로 프론트에서 사용자 안내가 가능하도록 합니다.
- 아이가 등록되지 않은 경우 문서·방문 기록 요청 전에 아이 등록을 안내해야 합니다.
- 가족 데이터와 문서는 보호자 권한 범위 안에서만 조회합니다.
- AI 답변은 의료적 진단을 대신하지 않으며, 응급·전문 진료가 필요한 경우 의료기관 상담을 안내합니다.
