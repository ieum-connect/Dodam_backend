# 김민지 로컬 시연 데이터

백엔드 저장소에서 실행합니다. 같은 PR의 프런트엔드와 백엔드를 사용합니다.

1. `docker compose up -d postgres`로 로컬 DB를 시작합니다.
2. 백엔드를 한 번 실행해 Flyway 마이그레이션을 적용합니다. 백엔드의 로컬 환경에 `DEMO_LOGIN=true`를 설정합니다.
3. PowerShell에서 `.\dummydata\seed-showcase.ps1`을 실행합니다. 백엔드에서 별도 문서 저장소를 사용한다면 같은 경로를 `-StorageRoot`로 넘깁니다. 상대 경로는 백엔드 저장소 기준입니다.
4. 프런트에서 **김민지 → 아이 선택 → 박도윤 (시연)**으로 들어갑니다. 둘째 기록은 **박다연 (시연)**에서 확인합니다.

- 병원 방문 5건, 연결 메모 5건, 원본 건강 문서 5건, 두 아이의 성장 기록 각 15건을 준비합니다.
- 건강검진 방문에 결과지와 메모가 연결됩니다. AI 도담의 **이전 대화**에는 가상 결과지의 예시 답변이 들어 있습니다. 이 스크립트는 OCR, 임베딩, 답변 생성 API를 호출하지 않습니다.
- 캘린더와 복약 화면에 일정이 표시되며, 문서에서 찾은 후보를 승인해 새 일정을 등록할 수 있습니다.
- 예방접종 완료 예시 8건을 준비합니다. 예방접종 화면의 일정 계산에는 기존 AI 백엔드 예방접종 API 연결이 필요합니다. 이 계산 경로는 유료 모델을 사용하지 않습니다.
- 맞춤 복지에 마포구 가구 정보와 가상 추천 사업을 넣습니다.

같은 DB에서 재실행해도 시연 레코드가 중복되지 않습니다. 기존 시연 일정 중 미완료 일정의 날짜는 실행일로 갱신됩니다. 시연용 원본은 로컬 저장소의 `showcase/`에 복사합니다.

예시 이미지에 인쇄된 날짜는 고정이며, 방문 기록과 캘린더의 시연 날짜는 초기화 시점을 기준으로 생성됩니다.
