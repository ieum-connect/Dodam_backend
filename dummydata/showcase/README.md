# 김민지 로컬 시연 데이터

백엔드 PR #49, 프런트엔드 PR #42, AI 백엔드 `develop`을 사용합니다. Windows에서 PowerShell 7, JDK 17, Python 3.11 이상과 Docker Desktop을 준비합니다.

1. 백엔드 저장소에서 `pwsh -File ./dummydata/start-showcase.ps1 -AiBackendPath ../ai-backend`를 실행합니다. 실제 AI 백엔드 체크아웃 폴더명에 맞게 경로를 바꿉니다. PostgreSQL, Spring, 예방접종 계산 서버를 시작하고 Flyway 적용 후 자료를 넣습니다.
2. 프런트엔드 저장소에서 `npm run dev`를 실행하고 `http://localhost:4173/`에서 **김민지**로 로그인합니다. **박도윤 (시연)**이 선택됩니다. 둘째 기록은 아이 전환에서 **박다연 (시연)**을 선택해 확인합니다.

이미 올바른 DB와 백엔드를 실행 중이라면 `./dummydata/seed-showcase.ps1`로 자료만 넣을 수 있습니다. 이 경우 Spring의 DB가 이 저장소의 로컬 Compose PostgreSQL인지 확인하고, 별도 저장소 경로를 쓰면 `-StorageRoot`를 맞춥니다. 예방접종은 실행 중인 계산 서버에 `AI_BASE_URL`과 `AI_INTERNAL_TOKEN`이 연결돼 있어야 합니다.

시연 스크립트는 Spring에 김민지로 로그인해 메모·방문·문서·접종·복지 정보가 조회된 뒤 완료 메시지를 출력합니다. `-BackendPort`로 기본 포트 8081을 바꿨다면 프런트 실행 전에 `$env:DODAM_BACKEND_URL = 'http://127.0.0.1:<포트>'`를 설정합니다.

- 병원 방문 5건, 육아 메모 10건(방문 연결 5건·태그 예시 5건), 원본 건강 문서 5건, 두 아이의 성장 기록 각 15건을 준비합니다.
- 건강검진 방문에 결과지와 메모가 연결됩니다. AI 도담의 **이전 대화**에서 가상 문서의 예시 대화 3개를 확인할 수 있습니다. 이 스크립트는 OCR, 임베딩, 답변 생성 API를 호출하지 않습니다.
- 캘린더와 복약에는 예정·완료 예시, 매일 및 월·수·금 반복 복약, 승인할 문서 후보를 넣습니다. 알림함에는 해당 화면으로 이동하는 복약·일정 알림과 읽은 가족 연결 알림을 넣습니다.
- 예방접종 완료 예시 8건을 준비합니다. 시연 실행 스크립트는 AI 백엔드 저장소의 예방접종 엔진만 불러오므로 외부 모델 키가 필요 없습니다.
- 맞춤 복지에 마포구 가구 정보, 가상 추천 사업, 두 아이의 관심 혜택을 넣습니다.

같은 DB에서 재실행해도 시연 레코드가 중복되지 않습니다. 기존 시연 일정 중 미완료 일정의 날짜는 실행일로 갱신됩니다. 시연용 원본은 로컬 저장소의 `showcase/`에 복사합니다.

예시 이미지에 인쇄된 날짜는 고정이며, 방문 기록과 캘린더의 시연 날짜는 초기화 시점을 기준으로 생성됩니다.
